# Architecture Decision Records

ADRs record decisions that affect security, signing, eligibility, automated spending, identity resolution, tenancy, provider behavior, or recovery.

Statuses:

- `Proposed`
- `Accepted`
- `Superseded by ADR-NNN`
- `Deprecated`

An accepted ADR is immutable. A changed decision is recorded in a new ADR that supersedes the old one.
